# NewsPortal

Django веб-приложение для новостного портала с системой публикации новостей, статей, комментариев и подписок. Платформа позволяет авторам публиковать контент, а пользователям - взаимодействовать с ним через комментарии и подписки на категории.


## Задача проекта

**Создать многофункциональный новостной портал, который позволяет:**

- Авторам публиковать новости и статьи в различных категориях
- Пользователям регистрироваться и аутентифицироваться через email и социальные сети
- Читателям комментировать публикации и оценивать контент
- Пользователям подписываться на интересующие категории
- Авторам управлять своими публикациями (создание, редактирование, удаление)
- Администраторам управлять всем контентом и пользователями
- Получать уведомления о новых публикациях в подписанных категориях

## Основные возможности

- Два типа контента: Новости (news) и Статьи (articles) с отдельными разделами
- Регистрация и аутентификация через email (с подтверждением) и социальные сети (Google, Yandex)
- Система подписок на категории с email-уведомлениями
- Многоязычность (английский, русский) с поддержкой перевода контента
- Локализация времени с выбором часового пояса пользователем
- Еженедельная рассылка новых публикаций по подпискам
- REST API для интеграции с другими системами
- Админ-панель с расширенными возможностями управления
- Кеширование публикаций для повышения производительности
- Система рейтингов для публикаций и комментариев
- Фильтрация и поиск публикаций по различным критериям

## Модели данных

### Пользователь (User)

- Стандартная модель Django User
- username, email, first_name, last_name
- Группы: authors, admin

### Автор (Author)

- Пользователь (связь 1:1)
- Рейтинг автора (вычисляется на основе активности)

### Категория (Category)

- Название (уникальное)
- Подписчики (связь M:M с User через CategoryUser)

### Публикация (Post)

- Автор (связь 1:M с Author)
- Тип публикации: 'article' или 'news'
- Дата создания
- Категории (связь M:M с Category через PostCategory)
- Заголовок
- Текст
- Рейтинг публикации

### Комментарий (Comment)

- Публикация (связь 1:M с Post)
- Пользователь (связь 1:M с User)
- Текст
- Дата создания
- Рейтинг комментария

### Промежуточные модели

- PostCategory: связь публикаций с категориями
- CategoryUser: связь пользователей с подписками на категории

## Технологии

- Backend: Django 5.2 + Django REST Framework
- Database: SQLite
- Templates: Django Templates + Bootstrap
- Email: SMTP (Yandex) с SSL
- Async tasks: Celery + Redis
- Аутентификация: Django Allauth (email + социальные сети)
- Интернационализация: Django i18n + django-modeltranslation
- Кеширование: FileBasedCache
- Планировщик задач: django-apscheduler
- Фильтрация: django-filter
- Администрирование: Стандартная Django admin + кастомные действия
- Изоляция: Docker

## Установка

### Способ 1: Локальная установка

**1. Клонировать репозиторий**

```bash
git clone https://github.com/erdes10032/news-paper
cd news-paper
```

**2. Создать виртуальное окружение**

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate  # Windows
```

**3. Установить зависимости**

```bash
pip install -r requirements.txt
cd newspaper
```

**4. Заполнить файл NewsPaper/.env своими данными**

**5. Выполнить миграции**

```bash
python manage.py makemigrations
python manage.py migrate
```

** 6. Создать суперпользователя**

```bash
python manage.py createsuperuser
```

** 7. Запустить сервер**

```bash
# Запуск Django сервера
python manage.py runserver
# В другом терминале запустить Celery worker
celery -A newspaper worker -l INFO
# И Celery beat для периодических задач
celery -A newspaper beat -l INFO
```

### Способ 2: Docker-установка

**1. Клонировать репозиторий**

```bash
git clone https://github.com/erdes10032/bulletin-board.git
cd bulletin-board/bulletinboard
```

**2. Заполнить файл NewsPaper/.env своими данными**

**3. Запустить проект**

```bash

```
Проект будет доступен по адресу: http://localhost:8000

**4. Остановить проект (опционально)**

```bash
docker-compose down
```

**5. Остановить проект с удалением всех данных (опционально)**

```bash
docker-compose down -v --rmi all
```

## Использование

### 1. Регистрация и вход

- Перейдите на главную страницу http://localhost:8000/
- Нажмите "Account" в навигационной панели
- Выберите "Sign Up" для регистрации через email или социальные сети
- Заполните форму регистрации
- Подтвердите email (письмо придет на указанный адрес)
- После подтверждения email вы сможете войти в систему

### 2. Стать автором

**Требование: Только пользователи в группе "authors" могут создавать публикации**

- После входа в систему перейдите в раздел "My groups"
- Нажмите "Become an author"
- Теперь у вас есть доступ к созданию новостей и статей

### 3. Создание публикации

**Доступно для пользователей в группе "authors"**

**Создание новости:**

- Перейдите в раздел "News"
- Нажмите кнопку "Make post"
- Заполните форму:
  - Выберите категории (можно несколько)
  - Введите заголовок (должен начинаться с заглавной буквы)
  - Введите текст (минимум 20 символов)
  - Нажмите "Save"

**Создание статьи:**

- Перейдите в раздел "Articles"
- Нажмите кнопку "Make post"
- Заполните форму аналогично созданию новости

**Ограничения:**

- Не более 3 новостей в день на одного автора
- Заголовок и текст не должны содержать запрещенных слов
- Заголовок не может быть идентичен тексту

**Пример успешного создания:**

- Публикация появляется в соответствующем разделе
- Все подписчики выбранных категорий получат email-уведомление
- Автор может редактировать и удалять свои публикации

### 4. Подписка на категории

- Перейдите к любой публикации
- В разделе "Category" найдите интересующую категорию
- Нажмите кнопку "Subscribe"
- Теперь вы будете получать уведомления о новых публикациях в этой категории

**Еженедельная рассылка:**

- Каждый понедельник в 8:00
- Новые публикации за прошедшую неделю
- По всем подписанным категориям

### 5. Управление профилем и настройками

- Выбор языка: На главной странице выберите предпочитаемый язык (русский/английский)
- Выбор часового пояса: На главной странице выберите ваш часовой пояс
- Тема оформления: Фон страницы автоматически меняется в зависимости от времени суток
- Группы пользователя: В разделе "My groups" можно посмотреть ваши группы и стать автором

## API Документация

**Приложение предоставляет REST API через Django REST Framework:**


| Метод   | Эндпоинт        | Описание              | Аутентификация |
|---------|-----------------|-----------------------|----------------|
| `GET`   | `/api/user/`    | Список пользователей  | Требуется      |
| `POST`  | `/api/user/`    | Создание пользователя | Требуется      |
| `GET`   | `/api/author/`  | Список авторов        | Требуется      |
| `POST` | `/api/author/`  | Создание автора       | Требуется      |
| `GET` | `/api/category/` | Список категорий      | Требуется      |
| `POST` | `/api/category/` | Создание категории    | Требуется      |
| `GET` | `/api/news/` | Список новостей       | Не требуется   |
| `POST` | `/api/news/` | Создание новости      | Требуется      |
| `GET` | `/api/articles/` | Список статей         | Не требуется   |
| `POST` | `/api/articles/` | Создание статьи       | Требуется      |
| `GET` | `/api/comment/` | Список комментариев   | Требуется      |
| `POST` | `/api/comment/` | Создание комментария  | Требуется      |

### Параметры API:

- Пагинация: По умолчанию 10 элементов на страницу
- Фильтрация: Доступна фильтрация публикаций по заголовку, категории и дате создания
- Аутентификация: SessionAuthentication и BasicAuthentication

### Пример использования API:

**Получение списка новостей:**

```bash
curl -X GET "http://localhost:8000/api/news/"
```

**Создание новости (с аутентификацией):**

```bash
curl -X POST "http://localhost:8000/api/news/" \
     -H "Content-Type: application/json" \
     -u "username:password" \
     -d '{
           "title": "Новая новость",
           "text": "Текст новости...",
           "category": [1, 2],
           "author": 1,
           "post_type": "news"
         }'
```

## Контекстные процессоры и middleware

### Timezone Middleware

- Определяет часовой пояс пользователя из сессии
- Позволяет выбирать часовой пояс на главной странице
- Автоматически конвертирует время для отображения

### Контекстные процессоры

- timezone_context - текущее время с учётом часового пояса
- Встроенные Django: auth, messages, i18n, request

## Кастомные теги и фильтры

### Пользовательские фильтры (custom_filters)

- censor - цензурирует запрещенные слова в тексте
- author - проверка, находится ли пользователь в группе "authors"
- admin - проверка, находится ли пользователь в группе "admin"

## Пользовательские теги (custom_tags):

- beautiful_post_type - преобразует 'news' → 'News', 'article' → 'Articles'
- url_replace - помогает в пагинации с сохранением параметров фильтрации

## Устранение неполадок

### Проблемы с email

- Проверьте переменные окружения в файле .env
- Убедитесь, что пароль приложения Yandex правильный
- Проверьте настройки SMTP в аккаунте Yandex
- Убедитесь, что EMAIL_USE_SSL = True

### Проблемы с Celery и Redis

- Проверьте, запущен ли Redis сервер
- Убедитесь в правильности настроек подключения к Redis в settings.py
- Проверьте логи Celery worker'а
- Убедитесь, что все зависимости установлены

### Проблемы с переводами

- Убедитесь, что файлы перевода скомпилированы: python manage.py compilemessages
- Проверьте настройки LANGUAGE_CODE и LANGUAGES в settings.py
- Убедитесь, что директория locale существует и содержит файлы перевода
- Перезапустите сервер после изменений в переводах

### Проблемы с кешированием

- Убедитесь, что директория cache_files существует и доступна для записи
- Проверьте настройки CACHES в settings.py
- При изменении публикаций кеш автоматически инвалидируется

### Проблемы с социальной аутентификацией

- Проверьте настройки социальных провайдеров в админ-панели
- Убедитесь, что SITE_ID установлен правильно
- Проверьте callback URL в настройках приложеня Yandex
